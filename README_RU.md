# Our Little World 2D

Небольшая браузерная life-sim игра на Canvas с пиксельной графикой. Она запускается как статический сайт: сборка, установка npm-пакетов и отдельный сервер приложений не нужны. Внешние изображения, музыка и шрифты не загружаются; для текста используется системный шрифт.

## Запуск в Windows 10

Рекомендуемый способ — встроенный сервер Python, чтобы браузер корректно загрузил JavaScript-модули.

1. Скачайте или распакуйте папку игры.
2. В Проводнике откройте эту папку, щёлкните адресную строку, введите `powershell` и нажмите Enter.
3. В открывшемся окне выполните:

   ```powershell
   py -m http.server 8000
   ```

   Если команда `py` не найдена, попробуйте `python -m http.server 8000`.

4. Откройте в браузере [http://localhost:8000](http://localhost:8000).
5. Чтобы остановить сервер, вернитесь в PowerShell и нажмите `Ctrl+C`.

При необходимости можно попробовать открыть `index.html` двойным щелчком. Некоторые браузеры блокируют ES-модули при запуске через `file://`; в таком случае используйте локальный сервер.

## Управление

- `A` / `D` или `←` / `→` — ходьба.
- `E` или `Enter` — взаимодействие поблизости.
- `Tab` — сменить управляемого героя.
- `Space`, `W` или `↑` — прыжок.
- `Esc` — открыть паузу или закрыть меню.
- На телефоне используйте экранные кнопки.

Кнопки над сценой ведут в дом, на улицу, в парк, кафе и лавку. Остальные комнаты и места доступны через кнопку «Места». Рюкзак, романтические действия, гардероб, магазин, мебель и настройки открываются в нижней панели. В меню «Вдвоём» можно взяться за руки и ходить вместе: управление остаётся у выбранного героя, второй идёт рядом. Повторное действие отпускает руки.

## Сохранения

Игра автоматически хранит прогресс в `localStorage` текущего браузера. Сохранение привязано к адресу сайта и профилю браузера: данные `localhost` не переносятся на опубликованный адрес GitHub Pages. На другом устройстве или в другом браузере будет отдельное сохранение. В настройках есть удаление сохранения с подтверждением.

## Публикация на GitHub Pages

Инструкция ниже только подготавливает публикацию. Она не отправляет файлы на GitHub и не меняет настройки уже опубликованного сайта.

Подготовленный набор находится в папке `github-pages/`. Загружайте **содержимое** этой папки в корень нового репозитория — саму папку `github-pages` внутрь репозитория помещать не нужно. В набор входят только файлы игры и README; локальные резервные копии в него не включены.

1. Создайте пустой репозиторий на GitHub. При создании можно добавить `README_RU.md`, если так удобнее; затем загрузите файлы из `github-pages/`.
2. Убедитесь, что в корне репозитория лежат `index.html`, `styles.css`, `.nojekyll` и папка `js/` с обоими JavaScript-файлами.
3. Откройте **Settings → Pages** в настройках репозитория.
4. В разделе сборки выберите **Deploy from a branch**, нужную ветку (обычно `main`) и папку **/(root)**, затем сохраните.
5. Дождитесь завершения публикации и откройте адрес, показанный GitHub Pages. Для проектного сайта он обычно имеет вид `https://<владелец>.github.io/<имя-репозитория>/`.
6. Если после обновления видна старая версия, обновите страницу с очисткой кэша (`Ctrl+F5`).

Сборка не нужна: это статический проект без `package.json`, npm, Vite, сервера приложений, базы данных и платного API. `.nojekyll` уже включён в подготовленный набор, чтобы GitHub Pages публиковал файлы без обработки Jekyll.

Точка входа — `index.html`. Ссылки на CSS и модули относительные (`styles.css`, `js/main.js`, `./characters.js`), поэтому работают и в подпапке репозитория. Имена файлов и регистр букв в путях должны совпадать.

## Структура

- `index.html` — Canvas, HUD и элементы интерфейса.
- `styles.css` — оформление и адаптивные правила.
- `js/main.js` — сцены, персонажи, предметы, управление, меню и сохранения.
- `js/characters.js` — процедурные пиксельные спрайты и состояния анимации.
- `github-pages/` — чистый комплект файлов, предназначенный для загрузки в корень репозитория GitHub Pages.

Этот рабочий каталог содержит 2D-версию. При аудите не удалялись и не перемещались файлы за его пределами; оригинальную 3D-версию не изменяли.

## Технические ограничения

- Перемещение идёт по горизонтальной оси и ограничено краями сцены. Отдельной физики платформ и общей системы столкновений персонажей с мебелью и окружением нет; мебель проверяет пересечение с другой мебелью при размещении.
- Графика в основном рисуется кодом в Canvas. Внешние sprite-файлы и звук не требуются.
- Сохранения локальны для браузера и origin сайта; облачной синхронизации нет.

## Проверка проекта

Проверить синтаксис исходных модулей из корня проекта можно командами:

```powershell
node --check js/main.js
node --check js/characters.js
```

Проверка подготовленного набора на Windows: откройте PowerShell в папке `github-pages/`, выполните `py -m http.server 8000`, затем откройте `http://localhost:8000/`. Чтобы проверить пути в подпапке, поместите содержимое `github-pages/` в папку с именем репозитория под корнем тестового HTTP-сервера и откройте URL с этой папкой. Проверьте загрузку сцены и CSS, меню и переходы, управление, совместную прогулку, а затем обновите страницу и убедитесь, что сохранение восстановилось.
## Особый вечер годовщины

Из главного меню или меню «Вдвоём» откройте «История годовщины». Персонажи приглашают друг друга в локацию «Наше место»: можно пройти короткое вступление или пропустить его, поговорить и сесть рядом. У праздничной коробки нажмите `E` или кликните по ней, чтобы открыть подарок; букет добавится в рюкзак, а письмо можно открыть отдельно. После подарка появляется финальная сцена с объятием и письмом. На кнопке «Закончить вечер» герои целуются под фейерверком и возвращаются в парк.
